# 🐂 牛头王 6 Nimmt!

> 经典桌游《6 Nimmt!》的数字实现版本，支持命令行对战、网页对战和 Q-Learning 强化学习训练。

---

## 📁 文件说明

| 文件 | 说明 |
|------|------|
| `nimmt.html` | **网页版**（推荐），单文件，浏览器直接打开即玩 |
| `nimmt.py` | 命令行对战版（1人类 + 5 AI） |
| `nimmt_ql.py` | Q-Learning 强化学习训练 + 对战 |
| `nimmt_q_table.pkl` | 训练好的 Q 表（训练后自动生成） |

---

## 🎮 游戏规则

- 共 **100 张牌**（1-100），6位玩家各发 **10 张**
- 牌桌摆 **5 列**，每列初始 1 张底牌（按升序排列）
- 每轮所有玩家**同时出 1 张牌**，按牌面从小到大依次放入牌桌

### 放牌规则

| 情况 | 结果 |
|------|------|
| 正常放入 | 放到末尾最大且比自己小的那列 |
| 你的牌是该列第 **7 张** | 💥 收走整列，获得该列全部牛头罚分 |
| 你的牌比**所有列末尾**都小 | 😱 必须自选一列收走 |

### 牛头数（罚分）

| 牌号规律 | 牛头数 |
|---------|-------|
| 普通牌 | 🐂 ×1 |
| 5 的倍数 | 🐂 ×2 |
| 10 的倍数 | 🐂 ×3 |
| 11 的倍数 | 🐂 ×5 |
| 55 | 🐂 ×7（最多）|

### 胜负

- 累计牛头超过 **66 分**时游戏结束
- **牛头最少**者获胜 🏆

## 🚀 快速开始

### 方式一：网页版（最简单，推荐发给朋友）

直接双击打开 `nimmt.html`，或右键用浏览器打开。

**无需安装任何东西！** 发给朋友一个文件即可。

---

### 方式二：命令行版

```bash
python3 nimmt.py
```

- 1 个人类玩家 + 5 个 AI
- 在终端中选择手牌序号出牌

---

### 方式三：Q-Learning 强化学习

#### 训练模型

```bash
python3 nimmt_ql.py train
```

训练 30000 局，Q 表保存到 `nimmt_q_table.pkl`，约需 10-20 秒。

训练过程输出示例：

```
Ep   2000 | ε=0.368 | 平均罚分=14.9🐂 | 平均排名=3.92 | 胜率=10.9%
Ep  10000 | ε=0.050 | 平均罚分=13.3🐂 | 平均排名=3.65 | 胜率=14.7%
Ep  30000 | ε=0.050 | 平均罚分=11.8🐂 | 平均排名=3.40 | 胜率=17.6%
```

#### 用训练好的模型对战

```bash
python3 nimmt_ql.py play
```

#### 先训练再直接看一局演示

```bash
python3 nimmt_ql.py
```

## 🤖 AI 策略说明

### 命令行 / 网页版（规则 AI）

| AI | 策略 | 行为特点 |
|----|------|---------|
| AI-甲 | greedy | 70% 选低风险，20% 选中间，**10% 赌一把出最大牌** |
| AI-乙 | safe | 90% 选最安全，10% 随机，偶尔意外 |
| AI-丙 | greedy | 同甲，激进型 |
| AI-丁 | random | **完全随机**，最不可预测 |
| AI-戊 | safe | 保守型 |

### Q-Learning 版（强化学习 AI）

**状态空间（6维离散特征）：**

| 特征 | 说明 |
|------|------|
| 手牌数量 | 当前剩余张数 |
| 安全牌数 | 放入后不触发收牌的张数 |
| 危险牌数 | 放入后会触发收牌的张数 |
| 最危险列剩余格 | 越小越危险 |
| 全场最小末尾值段 | 0~9 离散化 |
| 自身得分段 | 0~5 共 6 档 |

**奖励函数：**
- 本轮获得牛头数 × (-1)（即时奖励）
- 游戏结束排名奖励：第1名 +5，第6名 -5

**超参数：**

| 参数 | 值 | 说明 |
|------|----|------|
| α（学习率）| 0.1 | Q 值更新步长 |
| γ（折扣因子）| 0.95 | 未来奖励权重 |
| ε（初始探索率）| 1.0 | 从完全随机开始 |
| ε 最小值 | 0.05 | 保留 5% 探索 |
| ε 衰减 | 0.9995/局 | 逐渐从探索转向利用 |
| 训练局数 | 30000 | 约 10-20 秒 |

## 📊 Q-Learning 训练效果

| 训练局数 | 平均罚分 | 平均排名（6人） | 胜率 |
|---------|---------|--------------|------|
| 2,000 | 14.9🐂 | 3.92 | 10.9% |
