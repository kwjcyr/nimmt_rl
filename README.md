# 🐂 牛头王 6 Nimmt!

> 经典桌游《6 Nimmt!》的数字实现版本，支持命令行对战、网页对战，以及三种强化学习策略（Q-Learning、DQN、PPO）训练与对比。

---

## 📁 文件说明

| 文件 | 说明 |
|------|------|
| `nimmt.html` | **网页版**（推荐），单文件，浏览器直接打开即玩 |
| `nimmt.py` | 命令行对战版（1人类 + 5 AI） |
| `nimmt_ql.py` | Q-Learning 强化学习训练 + 对战 |
| `nimmt_dqn.py` | DQN（深度 Q 网络）强化学习训练 + 对战 |
| `nimmt_ppo.py` | PPO（近端策略优化）强化学习训练 + 对战 |
| `nimmt_compare.py` | 三种 RL 策略一键训练 + 胜率对比 |
| `nimmt_q_table.pkl` | 训练好的 Q 表（训练后自动生成） |
| `nimmt_dqn_model.pth` | 训练好的 DQN 模型（训练后自动生成） |
| `nimmt_ppo_model.pth` | 训练好的 PPO 模型（训练后自动生成） |

## 🎮 游戏规则

- 共 **100 张牌**（1-100），6位玩家各发 **10 张**
- 牌桌摆 **5 列**，每列初始 1 张底牌（按升序排列）
- 每轮所有玩家**同时出 1 张牌**，按牌面从小到大依次放入牌桌

### 放牌规则

| 情况 | 结果 |
|------|------|
| 正常放入 | 放到末尾最大且比自己小的那列 |
| 你的牌是该列第 **7 张** | 💥 收走整列，获得该列全部牛头罚分 |
| 你的牌比**所有列末尾**都小 | 😱 必须自选一列收走 |

### 牛头数（罚分）

| 牌号规律 | 牛头数 |
|---------|-------|
| 普通牌 | 🐂 ×1 |
| 5 的倍数 | 🐂 ×2 |
| 10 的倍数 | 🐂 ×3 |
| 11 的倍数 | 🐂 ×5 |
| 55 | 🐂 ×7（最多）|

### 胜负

- 累计牛头超过 **66 分**时游戏结束
- **牛头最少**者获胜 🏆

## 🚀 快速开始

### 方式一：网页版（最简单，推荐发给朋友）

直接双击打开 `nimmt.html`，或右键用浏览器打开。

**无需安装任何东西！** 发给朋友一个文件即可。

---

### 方式二：命令行版

```bash
python3 nimmt.py
```

- 1 个人类玩家 + 5 个 AI
- 在终端中选择手牌序号出牌

---

### 方式三：强化学习（Q-Learning / DQN / PPO）

三种算法均支持相同的命令行接口：

```bash
# Q-Learning（表格法，轻量快速）
python3 nimmt_ql.py train   # 训练，保存 nimmt_q_table.pkl
python3 nimmt_ql.py play    # 用模型对战展示
python3 nimmt_ql.py         # 先训练再展示

# DQN（深度 Q 网络，神经网络近似）
python3 nimmt_dqn.py train  # 训练，保存 nimmt_dqn_model.pth
python3 nimmt_dqn.py play
python3 nimmt_dqn.py

# PPO（近端策略优化，Actor-Critic）
python3 nimmt_ppo.py train  # 训练，保存 nimmt_ppo_model.pth
python3 nimmt_ppo.py play
python3 nimmt_ppo.py
```

#### 三种算法一键对比

```bash
python3 nimmt_compare.py
```

自动完成：随机基准评估 → Q-Learning 训练+评估 → DQN 训练+评估 → PPO 训练+评估 → 输出对比表格。

## 🤖 AI 策略说明

### 命令行 / 网页版（规则 AI）

| AI | 策略 | 行为特点 |
|----|------|---------|
| AI-甲 | greedy | 70% 选低风险，20% 选中间，**10% 赌一把出最大牌** |
| AI-乙 | safe | 90% 选最安全，10% 随机，偶尔意外 |
| AI-丙 | greedy | 同甲，激进型 |
| AI-丁 | random | **完全随机**，最不可预测 |
| AI-戊 | safe | 保守型 |

### 强化学习版（三种算法对比）

#### Q-Learning（表格 Q 值）

**状态空间（6维离散特征）：**

| 特征 | 说明 |
|------|------|
| 手牌数量 | 当前剩余张数 |
| 安全牌数 | 放入后不触发收牌的张数 |
| 危险牌数 | 放入后会触发收牌的张数 |
| 最危险列剩余格 | 越小越危险 |
| 全场最小末尾值段 | 0~9 离散化 |
| 自身得分段 | 0~5 共 6 档 |

| 参数 | 值 |
|------|----|
| 学习率 α | 0.1 |
| 折扣因子 γ | 0.95 |
| 探索率 ε 衰减 | 0.9995/局 |
| 训练局数 | 30000（约 20 秒） |

#### DQN（深度 Q 网络）

- **网络结构**：36维输入 → 128 → 128 → 64 → 10（动作数）
- **状态**：手牌归一化向量 + 牌桌特征 + 当前得分（共 36 维连续向量）
- **Experience Replay**：随机采样历史经验，打破时序相关
- **Target Network**：每 200 步同步一次，提升训练稳定性

| 参数 | 值 |
|------|----|
| 学习率 | 1e-3 |
| 折扣因子 γ | 0.95 |
| Replay Buffer | 20000 |
| Batch Size | 64 |
| 训练局数 | 30000（约 4 分钟） |

#### PPO（近端策略优化）

- **架构**：Actor-Critic 共享主干（128×128 Tanh），Actor Head 输出策略，Critic Head 输出状态价值
- **GAE**：λ=0.95，低方差优势估计
- **Clipped Loss**：ε=0.2，限制策略更新幅度防止过大跳变
- **每 10 局**收集轨迹数据，做 4 轮 PPO 更新

| 参数 | 值 |
|------|----|
| 学习率 | 3e-4 |
| 折扣因子 γ | 0.95 |
| GAE λ | 0.95 |
| Clip ε | 0.2 |
| PPO epochs | 4 |
| 训练局数 | 30000（约 72 秒） |

## 📊 三种 RL 策略对比（均训练 30000 局，评估 3000 局）

| 策略 | **胜率** | 前3率 | 平均排名 | 平均罚分 | 训练耗时 |
|------|--------|-------|--------|--------|--------|
| 🥇 **PPO** | **22.3%** | 58.3% | 3.17 | 10.0🐂 | ~72s |
| 🥈 **Q-Learning** | 17.0% | 52.7% | 3.40 | 11.6🐂 | ~20s |
| 🥉 **DQN** | 13.3% | 42.0% | 3.80 | 13.4🐂 | ~4min |
| ⬇️ 随机基准 | 12.0% | 43.6% | 3.76 | 13.6🐂 | — |

> 理论随机基准胜率（6人均匀分布）：16.7%

### 结论

- **PPO 最强**：Actor-Critic 架构 + GAE 优势估计使其学到稳健策略，胜率 22.3%，平均罚分仅 10 牛
- **Q-Learning 轻量高效**：无需 PyTorch，20 秒训练，胜率 17% 超越随机基准
- **DQN 潜力大**：30000 局对神经网络偏少，训练局数加到 100k+ 预计可超越 Q-Learning
